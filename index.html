VQE landscape: GD vs Adam vs QNG

Ansatz |ψ(θ)⟩ = Rz(θ₂)Ry(θ₁)|0⟩ with H = 0.6 Z + 0.8 X. Gradients come from the parameter-shift rule with shot noise, and QNG preconditions with the Fubini–Study metric.

Quantum kernel via incomplete Cholesky

Fidelity kernel k(x,x′) = |⟨φ(x)|φ(x′)⟩|² with angle encoding on 4 qubits. Greedy pivoting picks the most informative columns (white markers), so only n·r circuits run instead of n².
